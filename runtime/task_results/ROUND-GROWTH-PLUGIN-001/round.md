# ROUND-GROWTH-PLUGIN-001

## Round Name
AGOS_MERCHANT_HOMEPAGE_PROMOTION_WORKSPACE

## Phase
MERCHANT_HOMEPAGE_GROWTH_PLUGIN

## Goal
Refocus AGOS on pluggable merchant homepage promotion. Establish a local workspace structure where each merchant/product homepage can define target markets, social homepage matrix, value props, forbidden claims, target users, tone guardrails, and promotion goals.

## Safety Boundary
This round creates local, human-gated promotion workflow data only. It does not scrape login-only data, auto-post, auto-reply, auto-DM, create accounts, contact customers, impersonate users, or call platform write APIs.
