# ROUND-GROWTH-PLUGIN-006

## Round Name
AGOS_HUMAN_GATED_PROMOTION_REVIEW_CENTER

## Phase
MERCHANT_HOMEPAGE_GROWTH_ENGINE

## Goal
Build Human-Gated Promotion Review Center so all merchant homepage promotion artifacts enter one human review gate.

## Scope
- Read problem candidates, qualified opportunities, answer drafts, cross-platform promotion plans, CTA risks, and risk review data.
- Create unified review records.
- Support approve, reject, modify, and postpone as local decision records.
- Save modified versions when the human decision is `modify`.
- Keep all external execution disabled.

## Safety Boundary
Approve is not publish. This round does not auto-post, auto-reply, DM, operate real accounts, or call platform write APIs.
