# ROUND-EXT-004

## Round Name

PLATFORM_SURVIVAL_RULEBOOK

## Goal

Build platform survival rules so AGOS does not recommend spam, violations, or over-marketing.

## Scope

- Define platform rules for Reddit, X, TikTok, Instagram, YouTube, and Threads.
- Define forbidden patterns, safe CTA, posting cadence, and community risk.
- Connect the rulebook to promotion review center and external action sandbox outputs.
- Downgrade high-risk actions to `review_required` or `rejected`.

## Safety Boundary

This round does not publish, reply, DM, follow, like, log in, crawl, or call platform write APIs.
