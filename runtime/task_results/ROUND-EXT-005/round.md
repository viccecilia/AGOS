# ROUND-EXT-005

## Round Name

EXTERNAL_DRIFT_MONITOR

## Goal

Monitor whether external feedback and strategy expectations are drifting.

## Scope

- Compare expected external result against manual feedback.
- Flag strategy drift, platform drift, audience drift, and tone drift.
- Output drift report and recommendations.
- Connect to strategy evolution and promotion feedback learning.

## Safety Boundary

Drift only triggers recommendations. It does not automatically change external execution strategy.
