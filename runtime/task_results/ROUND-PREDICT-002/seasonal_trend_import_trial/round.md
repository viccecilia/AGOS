# ROUND-PREDICT-002

## Round Name
AGOS_READ_ONLY_SEASONAL_TREND_IMPORT_TRIAL

## Phase
PREDICTIVE_DEMAND_INTELLIGENCE

## Goal
Build a read-only seasonal trend import and analysis trial using local Google Trends-style sample exports.

## Scope
- Read local CSV/JSON/manual sample trend records.
- Map records to Japan tourism seasons from the Seasonal Demand Calendar.
- Generate market heat, demand interpretation, noisy-signal separation, and human review queue data.
- Show the trial in the Control Center.

## Safety Boundary
This round does not connect to real Google Trends, Google Search, social platforms, login pages, browser scraping, external posting, customer contact, driver dispatch, or platform write APIs. All imported records are sample-only.
