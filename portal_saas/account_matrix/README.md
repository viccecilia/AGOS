# Official Account Matrix Entry

R004 defines the workspace-scoped account matrix:

- every account profile belongs to one `workspace_id`;
- supported platforms are TikTok, Instagram, X, YouTube, Reddit, Threads, and SEO;
- account profile fields cover handle, display name, status, content strategy, risk status, and notes;
- credentials are explicitly out of scope: no passwords, cookies, tokens, API keys, or secrets should be stored here.

Later rounds can use this matrix to decide where content should be adapted, reviewed, or paused.
