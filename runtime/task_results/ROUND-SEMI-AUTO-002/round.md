# ROUND-SEMI-AUTO-002

## Round Name
AGOS_HUMAN_GATED_ACTION_QUEUE

## Phase
SEMI_AUTONOMOUS_RUNTIME

## Goal
Build a Human-Gated Action Queue so AGOS action recommendations wait for explicit human approval before they can become any local execution plan.

## Safety Boundary
Local approval queue only. Approve, reject, modify, and postpone decisions do not execute external platform actions.
