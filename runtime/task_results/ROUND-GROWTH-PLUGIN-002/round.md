# ROUND-GROWTH-PLUGIN-002

## Round Name
AGOS_PROBLEM_SEEKER_LOOP

## Phase
MERCHANT_HOMEPAGE_GROWTH_ENGINE

## Goal
Build a local, legal-source Problem Seeker Loop that finds candidate questions suitable for merchant homepage promotion.

## Scope
- Read merchant profile, target markets, target platforms, industry pack, forbidden claims, and target users.
- Support CSV, JSON, RSS, manual import, read-only API output, runtime normalized live data, seasonal trend import sample, and merchant promotion workspace inputs.
- Generate human-gated candidate questions for the active merchant homepage.
- Preserve workspace isolation and keep auto reply disabled.

## Safety Boundary
This round does not crawl login-only pages, call real platform APIs, auto-reply, auto-post, auto-DM, create accounts, contact users, or bypass platform limits.
