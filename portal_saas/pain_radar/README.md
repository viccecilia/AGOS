# Pain Point Radar Entry

R005 defines a local-data pain point radar:

- every pain point belongs to one `workspace_id`;
- supported fields include source, platform, market, audience, category, evidence, tags, and trend/value/urgency scores;
- `priority_score` is derived from trend, urgency, and value scores;
- this round uses local sample data only.

No real website crawling, scraping, platform login, or access bypass is part of this round.
